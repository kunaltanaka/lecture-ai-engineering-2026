## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：`lr` だけを 2e-4 から 5e-5 に下げた（`lora_r`=16、`num_train_epochs`=20、`seed`=42 などは同じ）。再実行は新しい T4 セッションで、上から実行した
- 結果（比較表や数字）：

| | lr = 2e-4（元） | lr = 5e-5 |
|---|---|---|
| 学習前 `format_rate` / `content_rate` | 0.095 / 0.000 | 0.095 / 0.000 |
| 学習後 `format_rate` | 1.000（21/21） | 1.000（21/21） |
| 学習後 `content_rate` | **0.857**（18/21） | 0.810（17/21） |
| 最終 loss（step 40） | 0.0139 | 0.1518 |
| 学習時間 | 223 秒 | 222 秒 |
| 退行 | なし | なし |

  - loss の推移（step 10 / 20 / 30 / 40）は、元が 1.563 / 0.084 / 0.018 / 0.014、`lr`=5e-5 が 2.134 / 0.929 / 0.298 / 0.152 だった。`lr` を下げると、同じ 40 ステップでは loss が下がりきらない
  - 形式遵守率は、どちらも 100% だった。形式を覚えるだけなら、`lr`=5e-5 でも足りた
  - 残った失敗は 4 件（元は 3 件）。`lr`=5e-5 では、根拠なしの質問 3 件（文字数の制限、フィードバック、参考文献の書き方）で、`needs_review: true` は正しく付いた。ただし、`answer` に「確認」の語が入らず（「FAQ には記載がありません」）、採点の必須語句で落ちた。さらに、「提出先は学習ポータルの「参考文献」欄です」のように、無関係な FAQ の文を混ぜた出力もあった。元の設定の失敗は断定が 2 件と確認要求で逃げたのが 1 件で、失敗の型が異なる。「PDF 以外でも出せますか」を確認要求で逃げた点は、どちらにも共通している
  - 注意：同じ seed でも GPU 上の学習は完全には再現しない。差は 1 問（0.857 と 0.810）なので、`lr` の効果と断定はできない。1 回ずつの実行で、条件を変えた繰り返しはしていない
  - 知識を問う質問（セクション 6）の分類は、どちらの設定でも同じだった（最終課題の締切は asserted、担当教員と次回のテーマは needs_review）
- ファインチューニングが向く場面・向かない場面についての考察：
  - 向く場面：出力の形式や文体のように、少ない例で決まった型を身につけさせたいとき。
    - 今回は 14 件の学習データを 20 周するだけで、形式遵守率が 9.5% から 100% になった。プロンプトで形式を指示しても守れなかった小さなモデルで、この差が出た
  - 向かない場面：知らないことへの判断
    - を学習で保証したい場面。形式が整った後も、FAQ に無い質問に近い項目で断定する失敗（成績の時期、事前予約の要否、最終課題の締切）が残った。FAQ の内容や新しい事実は、学習ではなく検索（RAG）で渡し、判断の誤りは評価データで測るのが現実的だと考える

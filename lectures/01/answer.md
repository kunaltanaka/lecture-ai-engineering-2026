  - そのうえで、「難易度 Level 1/2/3」「学習の3段階」「3つの階層」などの一般論を候補として挙げ、講師や教材に確認するよう勧めた。
  - 他の講座固有の質問も同じ傾向だった。
    - 「lecNN-start タグ」は「分からない」としつつ、「NN = Neural Network の講義の導入部」と、実際とは違う推測を述べた。
    - 「第2回で学ぶこと」は分からないと答え、こちらに情報提供を求めた。
  - 今回のモデルは、知らないことを確信して言い切るのではなく、「分からない」と認めるタイプだった。ただし「lecNN-start タグ」では、推測が実際と違うまま語られていた。
- 用語集の正しい意味と比べて気づいたこと：
  - 正しい定義（`data/glossary.json` の `homework-levels`）は、「基礎（講義内容の確認）／実装（自分でコードを書く）／発展（調査や試行）の3段階。どれか1つに取り組めば完了で、原則採点しない」というもの。
  - モデルの候補には「基礎・応用・発展」のような段階的な難易度があり、近い方向のものも含まれていた。しかし「どれか1つで完了」「採点しない」といった講座固有の中身は当てられない。
  - 正解に近そうな推測が混ざっていても、それを根拠にはできない。講座の資料を参照させる仕組み（第3回で作る用語集検索のエージェント）が必要だと分かった。

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - `ask.py` に `--temperature` オプションを足し、`generate_content` の `config`（`types.GenerateContentConfig(temperature=...)`）に渡した。
  - 質問は「AIE2026の講座の宿題にある『3レベル』とは何ですか？」。
  - temperature 0 と 1.5 で、それぞれ3回ずつ実行して比べた。モデルはローカルの1種類のみ。
- 結果：

  | temperature | 実行 | 出力トークン数 | 回答の冒頭・特徴 |
  |---|---|---|---|
  | 0 | 1〜3回目 | 579 / 579 / 579 | 3回とも同じ書き出し（「…確実な情報を持ち合わせておりません」）で、トークン数も一致 |
  | 1.5 | 1回目 | 487 | 「…具体的な情報がありません」。文中に中国語の語（「建议您」）が混入 |
  | 1.5 | 2回目 | 558 | 書き出しが違い、ブルームのタキソノミーを例に挙げた |
  | 1.5 | 3回目 | 555 | 「…情報を持ち合わせておりません」。講座のシラバスや教科書の確認を勧めた |

  - temperature 0 では、3回とも同じ出力トークン数（579）、同じ書き出しだった。
  - temperature 1.5 では、出力トークン数、書き出し、挙げる例が実行ごとに変わった。
  - temperature 1.5 の1回目には、中国語の語が混ざった。
- 気づき・疑問：
  - temperature を上げると、答えの表現や例が変わり、言語が崩れることもあった。
  - 一方で「知らない」という結論は、温度に関係なくどの回も変わらなかった。ばらつくのは表現で、モデルが持つ知識ではない。
  - 知らないことに答えさせる問題は、temperature を調整しても解決しない。外部の資料を渡す方向（第3回以降）で解決する。
  - temperature 0 でも完全に決定的とは限らない。今回は3回とも一致したが、GPU 計算や並列実行の影響で、どの環境でも一致するかは未確認。
  - 今回は1種類のモデルだけで試した。`AIE_MODEL` でモデルを変えた比較は未実施。
